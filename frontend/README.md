# 🏠 Home Help Service

> **Reliable Home Appliance Repair at Your Doorstep**

A modern and user-friendly web platform for booking home appliance repair services.

Home Help Service helps customers easily submit repair requests for appliances like **TV, AC, Refrigerator, Washing Machine, Cooler, and more.**

---

## ✨ Features

- 🏠 Clean & modern homepage
- 🔧 Appliance repair services
- 📋 Easy service request form
- 📱 Fully responsive design
- 📞 Customer contact details
- 📊 Admin dashboard
- 🔄 Service request status management
- 🔐 Admin authentication
- 💾 Database integration
